# КаваLab ☕ — кав'ярня з конструктором напою

Навчальний вебпроєкт (самостійна робота з дисципліни «Технології веброзробки та дизайну», варіант 11 «Кав'ярня КаваLab»).
Багатосторінковий сайт кав'ярні з головною функцією — **інтерактивним конструктором напою** з динамічним перерахунком ціни.

- 🌐 Сайт: https://kavalab-lviv.vercel.app
- 📦 Код: https://github.com/makcmodem22/kavalab
- 🧪 CI/CD: GitHub Actions → тести → автодеплой на Vercel при кожному `git push` у `main`

## Сторінки

| Сторінка | Що там |
|---|---|
| `index.html` — Головна | герой із живою «формулою» напою (келих із шарами), маніфест, хіти меню списком, приклад чека, відгуки стосом карток (Swiper) |
| `menu.html` — Меню | каталог із `data.json`: фільтр за категорією, ціною, «веган», пошук, сортування, модальне вікно з деталями |
| `constructor.html` — Конструктор | основа, розмір, молоко, до 3 сиропів, топінги, цукор, кількість, промокод; живий розрахунок, келих із шарами в мілілітрах; замовлення та «Мої напої» в `localStorage` |
| `about.html` — Про нас | історія, день кав'ярні за годинами, галерея плакатів (Swiper + GLightbox), команда, FAQ |
| `contacts.html` — Контакти | схема проїзду, форма зворотного зв'язку з перевіркою регулярними виразами та маскою телефону |

Шапка й футер спільні для всіх сторінок: у футері адреса, години роботи зі статусом «зараз відчинено / зачинено», навігація та розділи меню.

## Технології

- **HTML5** — семантична розмітка, перевірка `html-validate`
- **Tailwind CSS v4** (CLI) — адаптивна верстка, темна тема через варіант `dark:`
- **JavaScript (ES-модулі, без фреймворків)** — бізнес-логіка, `fetch` + `async/await` для `data/data.json`
- **CDN-бібліотеки**: [Swiper](https://swiperjs.com/) (відгуки й галерея), [GLightbox](https://biati-digital.github.io/glightbox/) (перегляд плакатів)
- **Vercel** — хостинг, Web Analytics; **GitHub Actions** — CI/CD
- Тести — вбудований `node:test`

## Структура

```
src/                 ← вихідники розмітки та стилів
  layout.html        спільний шаблон: <head>, шапка, футер
  pages/*.html       унікальний вміст 5 сторінок + 404
  input.css          тема Tailwind: кольори, шрифти, компоненти, анімації
scripts/
  build-pages.mjs    збирає src/pages + layout.html → public/*.html
public/              ← те, що публікується
  *.html             зібрані сторінки (не в git)
  css/styles.css     згенерований Tailwind (не в git)
  data/data.json     меню, відгуки, опції, рецепти й ціни конструктора
  js/
    main.js          спільне: тема, мобільне меню, статус у футері, аналітика
    data.js          завантаження data.json, обробка помилок, екранування
    pricing.js       ЧИСТА логіка ціни конструктора (тестується)
    formula.js       ЧИСТИЙ розрахунок шарів напою в мілілітрах (тестується)
    hours.js         ЧИСТА логіка «відчинено / зачинено» (тестується)
    validation.js    ЧИСТІ правила форми: регулярні вирази, маска телефону (тестується)
    glass.js         келих із шарами (спільний для головної та конструктора)
    art.js           генератор SVG-ілюстрацій напоїв
    builder.js, menu.js, home.js, about.js, contact.js — логіка окремих сторінок
  img/               логотип, плакати галереї, схема проїзду, OG-картинка, іконки
tests/               юніт-тести pricing, formula, hours і validation
.github/workflows/   CI/CD
```

Чому сторінки збираються скриптом: шапка, футер і метатеги однакові на всіх сторінках.
Щоб не копіювати їх шість разів, вони лежать в одному `src/layout.html`, а невеликий скрипт
без залежностей підставляє туди вміст кожної сторінки.

## Запуск локально

```bash
npm install
npm run build      # зібрати сторінки та CSS
npm run serve      # http://localhost:5173
npm run dev        # перезбирати сторінки й CSS при змінах (в окремому терміналі)
npm run check      # збірка + валідація HTML + тести
```

## Налаштування автодеплою

У репозиторії GitHub → *Settings → Secrets and variables → Actions* додати секрет `VERCEL_TOKEN` (створюється на vercel.com/account/tokens зі scope команди, де лежить проєкт). ID команди й проєкту вже вказані у workflow — вони не секретні.

## Обмеження прототипу

Серверної частини немає: форма й оформлення замовлення демонстраційні, дані не надсилаються. Кав'ярня, адреса й телефон вигадані.
Усю графіку (логотип, ілюстрації напоїв, плакати галереї, схему проїзду) створено за допомогою генеративного ШІ як векторні SVG, без стокових фото.
