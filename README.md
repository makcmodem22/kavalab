# КаваLab ☕ — кав'ярня з конструктором напою

Навчальний вебпроєкт (самостійна робота з дисципліни «Технології веброзробки та дизайну», варіант 11 «Кав'ярня КаваLab»).
Багатосторінковий сайт кав'ярні з головною функцією — **інтерактивним конструктором напою** з динамічним перерахунком ціни.

- 🌐 Сайт: https://kavalab-lviv.vercel.app
- 📦 Код: https://github.com/makcmodem22/kavalab
- 🧪 CI/CD: GitHub Actions → тести → автодеплой на Vercel при кожному `git push` у `main`

## Сторінки

| Сторінка | Що там |
|---|---|
| `index.html` — Головна | hero, переваги, хіти меню (з `data.json`), карусель відгуків (Swiper) |
| `menu.html` — Меню | каталог із `data.json`: фільтр за категорією, ціною, «веган», пошук, сортування, модальне вікно з деталями |
| `constructor.html` — Конструктор | основа, розмір, молоко, до 3 сиропів, топінги, цукор, кількість, промокод; живий розрахунок і візуалізація чашки; замовлення та «Мої напої» в `localStorage` |
| `about.html` — Про нас | історія, цифри, галерея (Swiper + GLightbox), команда, FAQ |
| `contacts.html` — Контакти | форма зворотного зв'язку з перевіркою регулярними виразами та маскою телефону |

## Технології

- **HTML5** — семантична розмітка, перевірка `html-validate`
- **Tailwind CSS v4** (CLI) — адаптивна верстка, темна тема через варіант `dark:`
- **JavaScript (ES-модулі, без фреймворків)** — бізнес-логіка, `fetch` + `async/await` для `data/data.json`
- **CDN-бібліотеки**: [Swiper](https://swiperjs.com/) (каруселі), [GLightbox](https://biati-digital.github.io/glightbox/) (перегляд зображень)
- **Vercel** — хостинг, Web Analytics; **GitHub Actions** — CI/CD
- Тести — вбудований `node:test`

## Структура

```
public/              ← те, що публікується
  *.html             5 сторінок + 404
  css/styles.css     згенерований Tailwind (не в git)
  data/data.json     меню, відгуки, опції й ціни конструктора
  js/
    main.js          спільне: мобільне меню, перемикач теми, аналітика
    data.js          завантаження data.json, обробка помилок, екранування
    pricing.js       ЧИСТА логіка ціни конструктора (тестується)
    validation.js    ЧИСТІ правила форми: регулярні вирази, маска телефону (тестується)
    builder.js       UI конструктора
    menu.js, home.js, about.js, contact.js, art.js
  img/               SVG-ілюстрації, OG-картинка, іконки
src/input.css        тема Tailwind (кольори, шрифти, компоненти)
tests/               юніт-тести pricing і validation
.github/workflows/   CI/CD
```

## Запуск локально

```bash
npm install
npm run build      # зібрати CSS
npm run serve      # http://localhost:5173
npm run dev        # перезбирати CSS при змінах (в окремому терміналі)
npm run check      # збірка + валідація HTML + тести
```

## Налаштування автодеплою

У репозиторії GitHub → *Settings → Secrets and variables → Actions* додати секрет `VERCEL_TOKEN` (створюється на vercel.com/account/tokens зі scope команди, де лежить проєкт). ID команди й проєкту вже вказані у workflow — вони не секретні.

## Обмеження прототипу

Серверної частини немає: форма й оформлення замовлення демонстраційні, дані не надсилаються. Кав'ярня, адреса й телефон вигадані.
Ілюстрації створено за допомогою генеративного ШІ (векторні SVG), без стокових фото.
